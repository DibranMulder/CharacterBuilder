## Style target

The [current playable characters](../../../artifacts/current_lineage_showcase.png) define the rendering style. Boss identities come from the original [encounter concepts](../README.md). The revision uses compact bodies, oversized expressive heads, chunky limbs, bold contours, broad color blocks and restrained soft shading. Surface detail is reduced so bosses read as larger members of the same sprite family. Comparison heroes are illustrative scale references, not replacement player assets.

## Generation

Generated using the built-in imagegen tool, one call per review sheet. All final PNGs are saved here; [exact prompts and source reference filenames](prompts.json) are included. `.gdignore` excludes the review artwork from Godot imports.

After the user approves the designs, update the corresponding boss panels in the eight lineage moodboards and Babylon. Do not treat creation of these review sheets as that approval.
