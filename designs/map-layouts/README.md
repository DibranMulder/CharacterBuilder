## How to read a detail sheet

- Pale platform edges and furniture tops are landing surfaces. Timber galleries, roofwalks, root shelves and stone terraces use distinct structural materials.
- All main raised landings connect to the public floor through an explicit stair, ladder or rope. Furniture supplies additional optional hops. Layout coordinates are design-sheet units; final game jump spacing still needs implementation playtesting.
- Golden `P1…` exits map exactly to the destination list. `R` marks local recovery. Numbered small characters map to named residents in the footer.
- The first footer explains the place’s spatial story; the second names destinations and inhabitants. Stronghold and story access rules remain intact.
- Soft, low-contrast background forms support detailed foreground routes. This atlas develops MapleStory-like layered side-scrolling traversal using this project’s own Human and Tidekin architecture.

## Coverage

The scope is the union of the existing atlas and the full DESIGN-0022 regional plan: **41 Human/Open Lands maps** (15 hometown, four training/wilderness, 22 planned outdoor maps) and **39 Tidekin maps** (17 hometown and 22 outdoor maps). The narrower runtime atlas alone would omit the planned Human maps.

Sources: [hometowns](../../docs/game/0014-hometown-maps.md), [world level plan](../../docs/game/0022-world-map-level-plan.md), [Tidekin regional description](../../docs/game/0023-tidekin-sea-region.md). NPC names follow the current hometown rosters.

## Editing and verification

- `tools/map_layouts/authored.py`: all 80 authored compositions, prop palettes and spatial narratives.
- `tools/map_layouts/build.py`: native SVG drawing components and detail-sheet construction.
- `tools/map_layouts/overviews.py`: cartographic layouts and exact portal graphs.
- `manifest.json`: platforms, supported climbs, props, inhabitants, portals and source coverage for every map.

From the repository root:

```sh
python3 tools/map_layouts/build.py
python3 tools/map_layouts/overviews.py
python3 tools/map_layouts/gallery.py
python3 tools/map_layouts/validate.py
python3 tools/map_layouts/render.py --all
```

Rendering uses the locally installed Chromium through Playwright; generation and static validation use only Python’s standard library. No rendering-performance claims are made for these design artifacts, and the runtime game was not modified.
